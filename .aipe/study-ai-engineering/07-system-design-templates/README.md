# 07 — AI system design templates

IK-style interview reframes for common AI system design prompts. Each template uses the 9-labelled-bullet shape (NOT the per-concept template): The prompt / Standard architecture / Data model / Key components / Scale concerns / Eval framing / Common failure modes / Applies to this codebase / How to make it apply.

## Files
